# Frontend

- React + Vite + TypeScript strict; data through the single TanStack Query client and the typed client in `web/src/api/` generated by `openapi-typescript` (`pnpm -C web gen:api`). Never hand-edit `schema.d.ts`.
- Design tokens only from `web/src/styles/tokens.css` ("regulatory gazette" palette, light and dark).
- Every screen has loading skeleton, empty, problem+json error with retry, and success states.
- WCAG 2.2 AA: keyboard reachable citation chips, `aria-live="polite"` for streamed claims, visible focus, labels on inputs.
- Only verified claims are rendered; never render raw model tokens.
