# Evals

- Committed datasets in `evals/datasets/*.vN.jsonl` are append-only by version: never edit an existing file, add `.v(N+1).jsonl` instead (the pre-tool hook blocks edits).
- Tune tau, reranker weights and prompts on the `dev` split only; the `test` split is for reporting.
- `evals/REPORT.md` is generated by `scripts/run_evals.py`; never hand-edit numbers. Offline numbers are labelled FakeLLM-produced.
- ACL leakage is a hard gate (= 0).
